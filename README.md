# GenArt

A modern, responsive website to showcase paintings as photos. Built with Vite, React, and TypeScript.

## Features
- Responsive grid of paintings (photos)
- Animated image expansion with info overlay
- Dark gray palette and beautiful fonts
- French and English support (i18n)
- About page for the artist
- Stylish footer with social media links

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the development server:
   ```sh
   npm run dev
   ```
3. Open your browser at [http://localhost:5173](http://localhost:5173)

## Customization
- Replace the placeholder images and info with your own artwork and descriptions.
- Update the About page with your biography.

---

This project uses [Vite](https://vitejs.dev/) and [React](https://react.dev/).
